# PolyLingo – AI Language Translation Studio

PolyLingo is a professional web-based language translation tool developed as part of the CodeAlpha Internship – Task 1.

It allows users to enter text, select source and target languages, and translate text using an online translation API.

## Features

- 🌐 Multiple language support
- 🔄 Source and target language swapping
- ✨ API-based text translation
- 📋 Copy translated text
- 📌 Paste text from clipboard
- 🔊 Text-to-speech for translated text
- 🗑️ Clear input and translation
- 🕘 Translation history
- 🌙 Dark and light mode
- ⌨️ Ctrl + Enter shortcut for translation
- 📱 Responsive design for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- MyMemory Translation API
- Browser Speech Synthesis API
- Local Storage

## How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Enter the text you want to translate.
5. Select the source and target languages.
6. Click **Translate Text**.
7. The translated result will appear in the translation panel.

## API

PolyLingo uses the **MyMemory Translation API** to process translation requests.

An active internet connection is required for translation.

## Project Objective

The objective of this project is to develop a simple, responsive and user-friendly language translation tool that can translate text between multiple languages using an online translation API.
