# 🤖 HelpBot – Smart FAQ Chatbot

HelpBot is a professional web-based FAQ chatbot developed as part of the **CodeAlpha Internship – Task 2**.

It helps users get quick answers to frequently asked questions using a predefined knowledge base and intelligent text-matching techniques.

## ✨ Features

- 🤖 Smart FAQ chatbot
- 🧠 NLP-style question matching
- 💬 Supports different ways of asking questions
- ⚡ Quick question suggestions
- ⌨️ Enter key support
- 🔄 Typing indicator
- 🌙 Dark and Light mode
- 🗑️ Clear chat functionality+
- 💾 Chat history using Local Storage
- 📱 Responsive user interface
- 🛡️ FAQ-based fallback response

## 🧠 How It Works

1. The user enters a question.
2. HelpBot processes and normalizes the text.
3. Important words are extracted from the question.
4. The question is compared with the FAQ knowledge base.
5. The most relevant intent is identified.
6. HelpBot displays the appropriate response.
7. If no suitable match is found, a fallback response is displayed.

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Enter a question in the chatbot.
5. HelpBot will analyze the question and provide the most relevant FAQ response.
